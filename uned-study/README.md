# UNED Study

Aplicación estable de estudio para Home Assistant OS.

Cada asignatura es exclusivamente de **tarjetas** o de **test**; ese contrato forma parte del diseño de la aplicación.

La interfaz está deliberadamente simplificada: selecciona una asignatura y pulsa **Continuar**. El motor decide internamente qué conviene repasar según errores, vencimiento, importancia y material nuevo.

También puedes elegir un tema concreto o realizar un simulacro en asignaturas tipo test.
